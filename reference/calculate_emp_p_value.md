# Calculate the Empirical p_value

This function calculates the Empirical p-value (emp_p_value) based on a
given object.

## Usage

``` r
calculate_emp_p_value(object)

# S4 method for class 'DGrowthR'
calculate_emp_p_value(object)
```

## Arguments

- object:

  A DGrowthR object which contains the Gaussian Process regression
  results.

## Value

A numeric value representing the calculated Empirical p-value.
