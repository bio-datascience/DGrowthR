# Plot Optical Density over Time

Calculates the optical density between the condition and control fitted
curves for each time point, plots both models as well as the optical
density difference between both fits.

## Usage

``` r
plot_od_difference(object)

# S4 method for class 'DGrowthR'
plot_od_difference(object)
```

## Arguments

- object:

  An object of class "DGrowthR".

## Value

A ggplot object representing the line plot.
