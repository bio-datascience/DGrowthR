# Merge phases This function is heavily based on the implementation available on AMiGA.

Merge phases This function is heavily based on the implementation
available on AMiGA.

## Usage

``` r
.merge_phases(df, idx1, idx2)
```

## Arguments

- df:

  A data.frame with the parameters of each potential growth phase.

- idx1:

  row number one

- idx2:

  row number two

## Value

A data frame with the merged growth phases.
