# Accessor for the likelihood ratio test result

This function retrieves the likelihood ratio test result from the growth
comparison slot

## Usage

``` r
lrt_statistic(object)

# S4 method for class 'DGrowthR'
lrt_statistic(object)
```

## Arguments

- object:

  An object from which to extract the perm_test_result slot.

## Value

The LRT test statistic
