# Plot Growth Comparison

This function plots the null and the alternative fits to the model

## Usage

``` r
plot_growth_comparison(object)

# S4 method for class 'DGrowthR'
plot_growth_comparison(object)
```

## Arguments

- object:

  An object of class "DGrowthR"

## Value

A list with two ggplot objects. One for the null model and another one
for the alternative.
