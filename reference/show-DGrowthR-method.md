# Display a summary of the DGrowthR object

This method displays a summary of the DGrowthR object, including the
first few rows of the od_data slot and the log-likelihood and posterior
probabilities of the alternative and null models.

## Usage

``` r
# S4 method for class 'DGrowthR'
show(object)
```

## Arguments

- object:

  A DGrowthR object.
