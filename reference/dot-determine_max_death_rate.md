# Estimate maximum death rate

Estimate maximum death rate

## Usage

``` r
.determine_max_death_rate(df, max_od_data)
```

## Arguments

- df:

  A data.frame with timepoint and first_derivative fields.

- max_od_data:

  A data.frame with the information output from .determine_max_growth()

## Value

A data.frame with the maximum death rate
